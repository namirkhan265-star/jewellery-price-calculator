# Version 2.5.29 - Metal Group Edit Feature
## Enable/Disable Making Charges & Wastage Charges

---

## 🎯 WHAT'S NEW

This update adds **Edit functionality** to Metal Groups with the ability to **enable/disable Making Charges and Wastage Charges** on a per-metal-group basis.

### Key Features:
✅ **Edit Metal Groups** - Rename metal groups and change units  
✅ **Enable/Disable Making Charges** - Hide making charge fields when not needed  
✅ **Enable/Disable Wastage Charges** - Hide wastage fields when not needed  
✅ **Dynamic UI** - Fields automatically show/hide based on selected metal  
✅ **Smart Calculation** - Disabled charges are set to 0 in price calculation  
✅ **Clean Frontend** - Disabled charges don't appear in price breakup

## 🚀 QUICK START

### For Users:

1. **Go to Metal Groups Page**
   - Navigate to: `Jewellery Calculator > Metal Groups`

2. **Edit a Metal Group**
   - Click the **Edit** button next to any metal group
   - Modal opens with current settings

3. **Configure Charges**
   - ✅ Check = Enable (fields will show)
   - ☐ Uncheck = Disable (fields will hide)

4. **Save Changes**
   - Click **Save Changes**
   - Changes apply immediately to all products using that metal group

### For Developers:

See **v2.5.29-DEPLOYMENT-GUIDE.md** for complete deployment instructions.

## 💡 USE CASES

### Use Case 1: Silver Products (No Making Charges)
**Scenario:** Your silver products don't have making charges

**Solution:**
1. Edit "Silver" metal group
2. Uncheck "Enable Making Charge"
3. Save

**Result:**
- Making charge fields hidden in product editor
- Making charge = 0 in price calculation
- Making charge row hidden in frontend price breakup

---

### Use Case 2: Diamond Products (No Wastage)
**Scenario:** Diamonds don't have wastage charges

**Solution:**
1. Edit "Diamond" metal group
2. Uncheck "Enable Wastage Charge"
3. Save

**Result:**
- Wastage field hidden in product editor
- Wastage = 0 in price calculation
- Wastage row hidden in frontend price breakup

---

### Use Case 3: Gold Products (Both Charges)
**Scenario:** Gold products have both making and wastage charges

**Solution:**
1. Edit "Gold" metal group
2. Keep both checkboxes checked
3. Save

**Result:**
- Both fields visible in product editor
- Both charges calculated normally
- Both rows shown in frontend price breakup

## 🔄 HOW IT WORKS

### 1. Admin Configuration
```
Metal Groups Page
    ↓
Click Edit Button
    ↓
Modal Opens
    ↓
Toggle Enable/Disable
    ↓
Save Changes
    ↓
Settings Stored in Database
```

### 2. Product Editor
```
Select Metal
    ↓
JavaScript Checks Metal Group Settings
    ↓
If Making Charge Disabled → Hide Section
If Wastage Disabled → Hide Field
    ↓
User Enters Product Details
    ↓
Save Product
```

### 3. Price Calculation
```
Get Product Data
    ↓
Get Metal Group Settings
    ↓
If Making Charge Disabled → Set to 0
If Wastage Disabled → Set to 0
    ↓
Calculate Final Price
    ↓
Save to WooCommerce
```

### 4. Frontend Display
```
Load Product Page
    ↓
Get Metal Group Settings
    ↓
If Making Charge Disabled → Don't Show Row
If Wastage Disabled → Don't Show Row
    ↓
Display Price Breakup
```

## 📊 TECHNICAL DETAILS

### Database Fields (Already Exist)
```sql
Table: wp_jpc_metal_groups
- enable_making_charge (tinyint) - 1 = enabled, 0 = disabled
- enable_wastage_charge (tinyint) - 1 = enabled, 0 = disabled
- making_charge_type (varchar) - 'percentage' or 'fixed'
- wastage_charge_type (varchar) - 'percentage' or 'fixed'
```

### Default Values
- `enable_making_charge` = 1 (enabled)
- `enable_wastage_charge` = 1 (enabled)
- `making_charge_type` = 'percentage'
- `wastage_charge_type` = 'percentage'
