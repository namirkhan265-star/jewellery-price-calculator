# 🚀 Quick Start Guide - v1.9.0

## For Non-Developers: 3 Simple Steps

### Step 1: Download (1 minute)
1. Go to: https://github.com/namirkhan265-star/jewellery-price-calculator
2. Click green **"Code"** button
3. Click **"Download ZIP"**
4. Save to your computer

### Step 2: Upload (2 minutes)
1. Login to WordPress admin
2. Go to **Plugins** → **Add New**
3. Click **Upload Plugin**
4. Choose the ZIP file you downloaded
5. Click **Install Now**
6. Click **Activate Plugin**

### Step 3: Verify (1 minute)
1. Look for **Jewellery Price** in left sidebar
2. You should see 4 NEW menu items:
   - **Shapes** ← NEW!
   - **Colours** ← NEW!
   - **Clarities** ← NEW!
   - **Cuts** ← NEW!
3. Click each one to see default data

## 🆘 Need Help?

### If menu items don't appear:
1. Deactivate the plugin
2. Reactivate the plugin
3. Refresh your browser

### If pages show errors:
1. Check all files uploaded correctly
2. Clear WordPress cache
3. Check file permissions

### If no default data:
1. Deactivate plugin
2. Reactivate plugin
3. Check Debug page
