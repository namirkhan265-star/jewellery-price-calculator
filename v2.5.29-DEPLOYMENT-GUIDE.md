# Version 2.5.29 - Deployment Guide
## Metal Group Edit with Enable/Disable Making/Wastage Charges

---

## 📋 OVERVIEW

This update adds Edit functionality to Metal Groups with the ability to enable/disable Making Charges and Wastage Charges. When disabled, these charges:
- ✅ Hide from product editor
- ✅ Skip calculation (set to 0)
- ✅ Hide from frontend price breakup

## ✅ TESTING CHECKLIST

After deployment, test these scenarios:

### Admin Testing
- [ ] Go to Metal Groups page
- [ ] Click Edit button on a metal group
- [ ] Modal opens with current values
- [ ] Change name - saves correctly
- [ ] Change unit - saves correctly
- [ ] Disable making charge - saves correctly
- [ ] Disable wastage charge - saves correctly
- [ ] Re-enable both - saves correctly

### Product Editor Testing
- [ ] Create/edit a product
- [ ] Select a metal with making charges ENABLED
  - [ ] Making Charges section is visible
  - [ ] Wastage field is visible
- [ ] Select a metal with making charges DISABLED
  - [ ] Making Charges section disappears
  - [ ] Can still enter other product details
- [ ] Select a metal with wastage DISABLED
  - [ ] Wastage field disappears
  - [ ] Making charges still visible (if enabled)

### Price Calculation Testing
- [ ] Product with making charges DISABLED
  - [ ] Price calculated correctly (making charge = 0)
  - [ ] Save product - price is correct
- [ ] Product with wastage DISABLED
  - [ ] Price calculated correctly (wastage = 0)
  - [ ] Save product - price is correct
- [ ] Product with both ENABLED
  - [ ] Price calculated correctly (includes both)

### Frontend Testing
- [ ] View product with making charges DISABLED
  - [ ] Making Charges row NOT shown in price breakup
  - [ ] Other charges shown correctly
- [ ] View product with wastage DISABLED
  - [ ] Wastage Charge row NOT shown in price breakup
  - [ ] Other charges shown correctly
- [ ] View product with both ENABLED
  - [ ] Both charges shown in price breakup
  - [ ] Values are correct

### Backward Compatibility Testing
- [ ] Existing products still display correctly
- [ ] Existing products calculate correctly
- [ ] Old metal groups (without settings) default to enabled
- [ ] No errors in browser console
- [ ] No PHP errors in debug log

## 🔧 TROUBLESHOOTING

### Issue: Edit button doesn't work
**Solution:** Clear browser cache and check JavaScript console for errors

### Issue: Fields don't hide/show when selecting metal
**Solution:** Make sure JavaScript snippet was added to product-meta-box-v2.js

### Issue: Price calculation still includes disabled charges
**Solution:** Verify price calculator changes were applied correctly

### Issue: Frontend still shows disabled charges
**Solution:** Check that accordion template changes were applied

### Issue: Modal doesn't open
**Solution:** Check that metal-groups.php was replaced with the new version

## 📊 DATABASE NOTES

**No database changes required!**

The database already has these fields from previous migrations:
- `enable_making_charge` (tinyint)
- `enable_wastage_charge` (tinyint)
- `making_charge_type` (varchar)
- `wastage_charge_type` (varchar)

Default values:
- Both charges default to ENABLED (1)
- Both types default to 'percentage'
