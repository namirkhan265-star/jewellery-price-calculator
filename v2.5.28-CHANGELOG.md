# Version 2.5.28 Changelog

## Bug Fix: Hide Discount When Disabled in Settings

### Problem
When "Enable Discount" was unchecked in plugin settings (`jpc_enable_discount = 'no'`), the discount section still appeared in:
1. Product editor meta box
2. Frontend price breakup accordion

### Solution

#### ✅ COMPLETED: Product Meta Box (`templates/product-meta-box/other-costs-section.php`)
- Added check for `jpc_enable_discount` setting
- Discount section now only displays when setting is enabled
- Matches behavior of Additional Cost Fields

**Commit:** 03e8b894a84ab138714181376f15e11e30ab974b

#### ⏳ PENDING: Frontend Accordion (`templates/shortcodes/product-details-accordion.php`)
- Need to add `jpc_enable_discount` check before displaying:
  - Discount row in price breakup
  - Savings badge at bottom

**Files provided for manual application:**
1. `DISCOUNT_FIX_INSTRUCTIONS.md` - Step-by-step manual instructions
2. `apply-discount-fix.php` - Automated PHP script to apply changes

### How to Apply Accordion Fix

**Option 1: Run the automated script**
```bash
cd /path/to/jewellery-price-calculator
php apply-discount-fix.php
```

**Option 2: Manual changes**
Follow instructions in `DISCOUNT_FIX_INSTRUCTIONS.md`

### Expected Behavior After Fix
- When `jpc_enable_discount` is set to 'no' in settings:
  - ✅ Discount section hidden in product editor
  - ✅ Discount row hidden in frontend accordion
  - ✅ Savings badge hidden in frontend accordion
  
- When `jpc_enable_discount` is set to 'yes' in settings:
  - ✅ All discount features work normally

### Testing
1. Go to Settings → Discount Calculation Settings
2. Uncheck "Enable Discount Feature"
3. Save settings
4. Edit a product → Discount section should be hidden
5. View product on frontend → Discount should not appear in price breakup
