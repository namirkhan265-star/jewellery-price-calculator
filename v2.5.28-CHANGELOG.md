# Version 2.5.28 Changelog

## Bug Fix: Hide Discount When Disabled in Settings ✅ COMPLETE

### Problem
When "Enable Discount" was unchecked in plugin settings (`jpc_enable_discount = 'no'`), the discount section still appeared in:
1. Product editor meta box
2. Frontend price breakup accordion

### Solution

#### ✅ COMPLETED: Product Meta Box (`templates/product-meta-box/other-costs-section.php`)
- Added check for `jpc_enable_discount` setting
- Discount section now only displays when setting is enabled
- Matches behavior of Additional Cost Fields

**Commit:** [03e8b89](https://github.com/namirkhan265-star/jewellery-price-calculator/commit/03e8b894a84ab138714181376f15e11e30ab974b)

#### ✅ COMPLETED: Frontend Accordion (`templates/shortcodes/product-details-accordion.php`)
- Added `$enable_discount` variable check from `jpc_enable_discount` setting (line 161)
- Updated discount row display condition (line 451)
- Updated savings badge display condition (line 500)
- Version updated to v2.5.28

**Commit:** [9a3a974](https://github.com/namirkhan265-star/jewellery-price-calculator/commit/9a3a974c105750d070ae7ede742b5366db7d5c6f)

### Expected Behavior After Fix ✅
- When `jpc_enable_discount` is set to 'no' in settings:
  - ✅ Discount section hidden in product editor
  - ✅ Discount row hidden in frontend accordion
  - ✅ Savings badge hidden in frontend accordion
  
- When `jpc_enable_discount` is set to 'yes' in settings:
  - ✅ All discount features work normally

### Testing Instructions
1. Go to **Settings → Discount Calculation Settings**
2. **Uncheck** "Enable Discount Feature"
3. **Save settings**
4. Edit a product → Discount section should be **hidden** in the editor ✅
5. View product on frontend → Discount should **not appear** in price breakup accordion ✅
6. **Check** "Enable Discount Feature" again
7. **Save settings**
8. Edit a product → Discount section should be **visible** in the editor ✅
9. View product on frontend → Discount should **appear** in price breakup accordion ✅
