## 🧪 HOW TO TEST

### Step 1: Download Fresh Plugin
1. Go to your GitHub repository
2. Click the green **Code** button
3. Click **Download ZIP**
4. Extract the ZIP file

### Step 2: Install Plugin
1. Go to WordPress Admin → Plugins → Add New
2. Click **Upload Plugin**
3. Choose the ZIP file
4. Click **Install Now**
5. Click **Activate Plugin**

### Step 3: Test Edit Functionality
1. Go to **Jewellery Calculator → Metal Groups**
2. You should see an **Edit** button next to each metal group
3. Click **Edit** on any metal group
4. A modal should pop up with:
   - Metal Group Name field
   - Unit field
   - Enable Making Charge checkbox
   - Enable Wastage Charge checkbox
5. Make changes and click **Save Changes**
6. Page should reload with your changes saved

## 🔍 TROUBLESHOOTING

### Issue: Edit button doesn't appear
**Check:**
- Clear browser cache (Ctrl+F5)
- Check if file `templates/admin/metal-groups.php` was updated
- File size should be around 15KB (not 6KB)

### Issue: Modal doesn't open when clicking Edit
**Check:**
- Open browser console (F12)
- Look for JavaScript errors
- Make sure jQuery is loaded

### Issue: Save doesn't work
**Check:**
- Open browser console (F12) → Network tab
- Click Save and look for `admin-ajax.php` request
- Check the response - should show success or error message

### Issue: "Permission denied" error
**Check:**
- Make sure you're logged in as Administrator
- Check if user has `manage_woocommerce` capability
